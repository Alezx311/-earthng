EarthNG - справжні місця в BeamNG.drive (тестова збірка)
=========================================================

Що це
-----
Мод для BeamNG.drive: обираєте будь-яку точку на мапі України, «висаджуєтесь» і їдете
справжніми вулицями з OpenStreetMap. Дороги, рельєф, будинки, дерева генеруються на льоту
навколо авто окремою програмою-компаньйоном (вона в цьому архіві разом із Python і даними).

Потрібно
--------
- Windows 10/11, BeamNG.drive 0.39 зі Steam.
- ~12 ГБ вільного місця (архів ~5 ГБ + розпаковане + кеш тайлів), 16 ГБ RAM (краще 32),
  4+ ядра процесора (краще 8+: будинки генеруються паралельно).
- Інтернет лише для картинки мапи при виборі точки (дороги генеруються офлайн).

Встановлення
------------
1. Розпакуйте архів у теку без кирилиці та пробілів у шляху, наприклад C:\EarthNG.
2. Більше нічого встановлювати не треба: Python і всі дані вже всередині.

Linux (експериментально)
------------------------
Вбудований Python лише для Windows, тож на Linux потрібен системний python3 (3.10+) з venv
(Debian/Ubuntu: sudo apt install python3 python3-venv). У теці пакета:
    bash start.sh
Перший запуск сам ставить пакети Python у venv-linux/ (потрібен інтернет). Профіль BeamNG
шукається і для нативної збірки, і для Proton; якщо не знайшовся:
    bash start.sh --userfolder "/шлях/до/BeamNG.drive/current"
Інші параметри: --workers N, --nogame. Вікна запуску (EarthNG.bat) на Linux поки немає.

Запуск
------
1. Двічі клацніть EarthNG.bat. Відкриється вікно запуску з налаштуваннями:
   тека профілю BeamNG, дані OSM, кількість процесів генерації, радіус далекого плану,
   чи запускати гру. Налаштування запам'ятовуються (launcher.json). Кнопка «Запустити»:
   - скопіює мод у <тека профілю>\mods\earthng_planet.zip;
   - запустить BeamNG.drive через Steam (якщо позначено);
   - запустить компаньйон; його журнал видно внизу вікна. НЕ закривайте вікно, поки граєте.
   Запасний варіант без вікна: start.bat (те саме в консолі, типові налаштування).
2. У грі: Freeroam -> рівень «Earth2Road - Планета».
3. З'явиться вікно з мапою: оберіть точку (кліком, координатами або кнопкою міста:
   райони Києва, міста Київщини, обласні центри) і натисніть «Висадитися тут».
   Точку краще ставити на дорогу.
4. Перший запуск у новому районі: 40-70 с (індексація доріг навколо точки). Далі -
   кілька секунд. Можна їхати; світ генерується попереду авто.

У грі
-----
- Міні-вікно Earth2Road: стан тайлів, кнопка «Обрати інше місце» і перемикач стилю:
  Реальний / Мультяшний / Макет / Синтвейв / Ніч / Дощ / Кіберпанк / Зима / Осінь.
  Ніч, Дощ і Кіберпанк - з ліхтарями й світлом у вікнах; Дощ і Зима - з опадами.
- Зона навколо висадки - від ~55x55 км (великі міста) до ~120x120 км (села). За 3 км
  до краю з'явиться попередження: далі доріг немає, висадьтеся в новій точці
  (кнопка «Обрати інше місце»). Нова висадка в будь-якому місці країни - знову 40-70 с.
- Дорога з'являється першою, будинки й дерева - слідом за кілька секунд.
- Трафік: кнопки «Вимк / Мало / Середньо / Багато» в міні-вікні. Машини гри їздять
  дорогами, які вже згенеровані навколо вас (приблизно 1 км), і з'являються заново попереду.
- Погода і час доби: звичайне меню гри «Середовище» (Environment) - час, хмари, дощ, туман,
  вітер. Сонце стоїть так, як у точці висадки.

Якщо щось не так
----------------
- Інша тека користувача BeamNG:  поле «Тека профілю BeamNG» у вікні запуску
                                 (або start.bat -UserFolder "D:\BeamNG\current")
- Слабкий ПК / мало пам'яті:     «Процеси генерації» = 2, «Далекий план» = 1500
                                 (або start.bat -Workers 2)
- Гру не знайдено для текстур фасадів: задайте змінну BEAMNG_DIR = тека гри
  (там, де BeamNG.drive.exe), інакше фасади будуть одноколірні.
- «Компаньйон не відповідає» у грі: перевірте, що вікно запуску відкрите, а в журналі немає помилок.
- Для звіту про проблему: скріншот, точка висадки і файли
  work\fast-index\*\region.json та вміст журналу у вікні запуску.
